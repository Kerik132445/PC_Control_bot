# PC Control Telegram Bot (aiogram 3)

Асинхронный Telegram-бот на базе **aiogram 3** для дистанционного управления и мониторинга компьютера на базе ОС Windows. Позволяет контролировать процессы, перезагружать ПК, регулировать громкость и делать скриншоты экрана прямо из мессенджера.

## 🚀 Ключевые фичи

* 📊 **Мониторинг системы:** Получение актуальной информации о нагрузке на ЦП, оперативной памяти и свободном месте на дисках (C/D).
* ⚙️ **Управление процессами:** Просмотр ТОП-10 самых тяжелых процессов и возможность "прибить" любой из них по имени.
* 🔊 **Регулировка звука:** Плавное изменение системной громкости с визуальной шкалой (`▇▇▇░░`).
* 📸 **Скриншоты:** Запрос текущего снимка экрана в один клик.
* 🔌 **Питание:** Безопасное выключение и перезагрузка ПК с таймером отсчета.
* 🔒 **Безопасность:** Доступ к боту жестко ограничен по `ADMIN_ID`. Автоматическая генерация скрытого конфига при первом запуске.

## 🛠️ Стек технологий

* **Language:** Python 3.10+
* **Framework:** `aiogram 3.x` (Asynchronous Telegram Bot API)
* **System Utilities:** `psutil`, `pyautogui`, `pycaw` (для работы со звуком Windows)

## 📦 Установка и запуск

### 1. Клонирование репозитория
Откройте терминал и выполните команду:
```bash
git clone [https://github.com/Kerik132445/PC_Control_bot.git](https://github.com/Kerik132445/PC_Control_bot.git)
cd PC_Control_bot
```

### 2. Установка зависимостей
Рекомендуется использовать виртуальное окружение. Для установки необходимых библиотек выполните:
```bash
pip install -r requirements.txt
```

### 3. Запуск бота
Запустите скрипт:
```bash
python main.py
```

⚠️ Важно: При первом запуске в консоли потребуется ввести токен вашего Telegram-бота и ваш личный Telegram ID. Бот автоматически создаст скрытый файл конфигурации kiryha_pc_control_config.json и перезапустится в фоновом режиме.
